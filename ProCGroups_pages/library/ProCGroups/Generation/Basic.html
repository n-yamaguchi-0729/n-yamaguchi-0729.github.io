ProCGroups.Generation.Basic

31 Theorems | 10 Definitions

This module defines topological generation, convergence to one, the corresponding cardinal ranks, and the finite word-product filtration of a set. It develops extensionality, closed-generated-subgroup, image, quotient, and continuous-equivalence lemmas that form the basic API for generator arguments in profinite groups.

def ConvergesToOneAlongOpenSubgroups (X : Set G) : Prop :=
  ∀ U : OpenSubgroup G, (X \ (U : Set G)).Finite

The weaker condition obtained by testing convergence only against open subgroups.

This agrees with ConvergesToOne for nonarchimedean groups, but is deliberately kept separate: on a general topological group, open subgroups need not form a neighborhood basis at 1.

Definition ProCGroups.Generation.topologicalRank GitHub 
noncomputable def topologicalRank
    (G : Type u) [Group G] [TopologicalSpace G] [IsTopologicalGroup G] :
    Cardinal :=
  sInf {κ : Cardinal |
    ∃ X : Set G, TopologicallyGenerates (G := G) X ∧ Cardinal.mk X = κ}

The least cardinality of a topological generating set.

The candidate set is always nonempty: Set.univ topologically generates every group. Thus this definition never uses the accidental value Cardinal.sInf ∅ = 0.

Definition ProCGroups.Generation.convergentGeneratorRank GitHub 
noncomputable def convergentGeneratorRank
    (G : Type u) [Group G] [TopologicalSpace G] [IsTopologicalGroup G] :
    Option Cardinal := by
  classical
  exact
    if h : ∃ X : Set G, GeneratesAndConvergesToOne (G := G) X then
      some (sInf {κ : Cardinal |
        ∃ X : Set G, GeneratesAndConvergesToOne (G := G) X ∧ Cardinal.mk X = κ})
    else
      none

The optional least size of a generating set which also converges to 1.

Unlike topologicalRank, the relevant family of cardinals can be empty, so absence is represented by none instead of being silently identified with cardinal zero.
