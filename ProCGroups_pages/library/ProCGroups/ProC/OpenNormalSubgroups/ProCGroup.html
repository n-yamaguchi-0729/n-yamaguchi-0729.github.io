ProCGroups.ProC.OpenNormalSubgroups.ProCGroup

33 Theorems | 15 Definitions | 1 Abbreviation | 2 Instances

HasOpenNormalBasisInClass C G says exactly that the identity neighborhoods of G have a basis of open normal subgroups whose quotients lie in C. It does not assert compactness, Hausdorffness, total disconnectedness, or even the topological-group laws.

For an ambient ProfiniteGrp, this is precisely the additional property used to define the bundled category ProCGrp C.

The module also packages the class-indexed open normal subgroups, their quotient projections and transition maps, and the separation consequences of a Hausdorff open-normal basis.

Definition ProCGroups.ProC.HasOpenNormalBasisInClass GitHub 
def HasOpenNormalBasisInClass (C : FiniteGroupClass.{u})
    (G : Type u) [Group G] [TopologicalSpace G] : Prop :=
  ∀ W : Set G, IsOpen W → (1 : G) ∈ W →
    ∃ U : OpenNormalSubgroup G,
      ((U : Subgroup G) : Set G) ⊆ W ∧ C (G ⧸ (U : Subgroup G))

The identity-neighborhood basis property for open normal subgroups with quotient in \(C\).

This predicate deliberately carries no profiniteness assumptions. A bundled pro-\(C\) object is an ambient ProfiniteGrp satisfying this additional property, as expressed by ProCGrp C.

    (hHer : FiniteGroupClass.Hereditary C) (f : G →ₜ* H)
    (U : OpenNormalSubgroupInClass C H) : OpenNormalSubgroupInClass C G :=
  let N : OpenNormalSubgroup G :=
    OpenNormalSubgroup.comap f.toMonoidHom f.continuous_toFun U.1
  ⟨N, by
    let qmap : G ⧸ (N : Subgroup G) →* H ⧸ (U.1 : Subgroup H) :=
      QuotientGroup.map (N := (N : Subgroup G)) (M := (U.1 : Subgroup H))
        f.toMonoidHom (by
          intro x hx
          exact hx)

      rw [← MonoidHom.ker_eq_bot_iff qmap]
      ext z
      constructor
      · intro hz
        rcases QuotientGroup.mk'_surjective (N : Subgroup G) z with ⟨x, rfl⟩

          apply (QuotientGroup.eq_one_iff (N := (U.1 : Subgroup H)) (f x)).1

        exact (QuotientGroup.eq_one_iff (N := (N : Subgroup G)) x).2 hxU

        simp only [one_mem]
