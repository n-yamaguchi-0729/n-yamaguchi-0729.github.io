This file packages linearly ordered families of subgroups, defines their carrier union and intersection, and gives membership and trivial-intersection criteria used in transfinite closed-normal series arguments.

abbrev SubgroupChain (ι : Type v) (G : Type u) [Group G] := ι → Subgroup G

Definition ProCGroups.LocalWeight.subgroupChainCarrier 
def subgroupChainCarrier (c : SubgroupChain ι G) : Set G :=
