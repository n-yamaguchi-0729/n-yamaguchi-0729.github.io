This module defines the finite-state tau rewriting of signed words into Schreier symbols and proves compatibility with concatenation, cancellation, reduction, and free-group multiplication.

def tauList : Q → List (X × Bool) → FreeGroup (FiniteSchreierSymbol X Q)
  | _q, [] => 1
  | q, (x, true) :: xs =>
      FreeGroup.of (q, x) * tauList (D.transition q x) xs
  | q, (x, false) :: xs =>
      (FreeGroup.of (D.inverseTransition q x, x))⁻¹ *
        tauList (D.inverseTransition q x) xs
