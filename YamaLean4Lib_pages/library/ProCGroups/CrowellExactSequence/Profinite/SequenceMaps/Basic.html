ProCGroups.CrowellExactSequence.Profinite.SequenceMaps.Basic

3 Theorems | 3 Definitions

This file defines the completed differential boundary and the maps from completed and separated differential modules to the completed \(\mathbb Z_C\)-group algebra. It proves their values on universal differentials and compatibility with separation.
